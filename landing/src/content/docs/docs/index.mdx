## Headless browsing built for agent workloads

Domjet is embedded in Node.js as WebAssembly. Node supplies the host environment and V8 runtime;
the engine supplies the DOM, CSS, layout, paint, browser contexts, and Chrome DevTools Protocol state.

<CardGrid>
  <Card title="Direct Node API" icon="seti:npm">
    Create browsers, contexts, and pages without starting a listener or managing a child process.
  </Card>
  <Card title="Real rendering" icon="seti:image">
    Use layout, screenshots, PDF, and canvas-backed paint from the same engine that owns the DOM.
  </Card>
  <Card title="Familiar tooling" icon="puzzle">
    Connect existing Playwright and Puppeteer workflows through CDP adapters when you need them.
  </Card>
  <Card title="Portable by design" icon="rocket">
    Ship one Node dependency instead of downloading and supervising a separate Chromium build.
  </Card>
</CardGrid>

## Start small

Install Domjet and open a page with the direct API:

```bash
npm install domjet
```

```js
import { createBrowser } from 'domjet';

const browser = await createBrowser();
const page = await browser.newPage();

await page.goto('https://example.com');
console.log(await page.evaluate(() => document.title));

await browser.close();
```

Continue to [Get started](/docs/getting-started/) for the first complete workflow.
