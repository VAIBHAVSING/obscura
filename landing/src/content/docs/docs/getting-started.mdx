Domjet runs as a Node.js package. You do not need to install Chromium or launch a separate browser
process.

<Aside type="note" title="Package launch">
  `domjet` is the intended npm package name for the renamed project. Publish or reserve it before
  linking this production site to the npm registry.
</Aside>

## Requirements

- Node.js 22 or newer
- An ESM project, or a CommonJS project using dynamic `import()`

## Your first page

<Steps>
1. Install Domjet.

   ```bash
   npm install domjet
   ```

2. Create a browser and navigate to a page.

   ```js title="example.mjs"
   import { createBrowser } from 'domjet';

   const browser = await createBrowser();
   const page = await browser.newPage();

   await page.goto('https://example.com');
   const title = await page.evaluate(() => document.title);
   console.log(title);

   await browser.close();
   ```

3. Run the script.

   ```bash
   node example.mjs
   ```
</Steps>

## Capture a screenshot

The page API can return the image bytes and optionally write them to a path:

```js
const image = await page.screenshot({
  path: 'page.png',
  fullPage: true,
});

console.log(`Wrote ${image.byteLength} bytes`);
```
